## Usage recommendation

Use GIFs sparingly in the main README so that the page remains readable. The most useful README structure is:

1. One global method-error figure near the top.
2. One row comparing Euler, RKF5 and Velocity Verlet on the chaotic case.
3. One row with representative periodic and Solar-System examples.
4. Additional images inside the detailed documentation files.
