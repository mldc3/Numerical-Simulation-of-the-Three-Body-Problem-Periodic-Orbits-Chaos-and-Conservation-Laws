# Acknowledgements

This project was inspired in part by Ching-Yin Ng's `grav_sim` project and the tutorial **“5 steps to N-body simulation”**.

`grav_sim` is an $N$-body gravity simulation library with C and Python APIs, and its tutorial provides a step-by-step introduction to writing clean gravitational $N$-body simulations in Python.

- Tutorial: <https://alvinng4.github.io/grav_sim/5_steps_to_n_body_simulation/>
- Repository: <https://github.com/alvinng4/grav_sim>

The present repository is an independent computational-physics practice project. This acknowledgement is included for transparency because the tutorial helped motivate the simulation workflow and the way the numerical $N$-body problem is presented.
